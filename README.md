# Kamen

Фотореалистичный прототип облицовки дома природным камнем при прокрутке.

GitHub Pages: https://mumortsev.github.io/Kamen/

Статический HTML/CSS/JavaScript без сборки. Изображения — сгенерированная демонстрационная визуализация, не портфолио реального подрядчика. При прокрутке фотографический каменный фасад раскрывается участками поверх состояния до облицовки. Сцена имеет фиксированный ракурс.

Публикация: `.github/workflows/pages.yml`, ветка `main`. Проверки и тесты не добавлены и не запускались по просьбе владельца.
