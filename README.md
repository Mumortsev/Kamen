# КаменьТорг23 — интерактивный hero

https://mumortsev.github.io/Kamen/

Неподвижный полноэкранный hero. Колесо мыши, свайп или клавиши управляют раскрытием природного камня. Страница и кадр не прокручиваются: сцена закреплена через position: fixed, прокрутка документа отключена. В начале видна только стрелка вниз. После облицовки появляются шапка и предложение.

Отдельные горизонтальная и вертикальная композиции. Фотореалистичные изображения сгенерированы как демонстрация применения материала. Шрифт Onest подключен локально; лицензия включена в assets/fonts/Onest-OFL.txt. Onest не заявляется как релиз 2026 года: это замена ранее выбранной акцидентной гарнитуры по обратной связи владельца.

CSS и JavaScript включены в index.html для атомарной доставки. app.js и style.css — исходники тех же блоков. Публикация в GitHub Pages через main.

Проверки и тесты не запускались по просьбе владельца.
