# КаменьТорг23 — интерактивный hero

https://mumortsev.github.io/Kamen/

Один полноэкранный закрепленный кадр. Первое состояние — кирпичный дом и подсказка прокрутки. Прокрутка раскрывает природный камень участками снизу вверх. После облицовки появляются шапка, заголовок и кнопки. На мобильных используется отдельная вертикальная сцена того же дома. Высота кадра фиксируется по большому viewport и не пересчитывается при скрытии адресной строки.

Изображения — сгенерированная демонстрационная визуализация, не портфолио реальной компании. Геометрия крыши, окон и окружения остается на базовом кадре: материал раскрывается через маски стен.
