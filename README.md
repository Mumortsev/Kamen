# КаменьТорг23 — интерактивный hero

https://mumortsev.github.io/Kamen/

Полноэкранная фиксированная сцена: темный бетон превращается в светлый природный камень. Колесо, свайп и клавиши управляют материалом; документ не прокручивается. Раскрытие начинается от первого движения, расписание участков учитывает реальную маску стен.

Заголовок — Lora, навигация, описание и кнопки — Golos Text. Шрифты локальные, лицензии в assets/fonts. Заголовок отделен от нижней группы описания и действий. Под нижней группой — контрастный темный градиент. Начальная подсказка — крупная центральная стрелка с плавным вертикальным движением.

Демонстрационные изображения сгенерированы, это не портфолио подрядчика. Для телефона и десктопа отдельные кадры. CSS/JS включены в index.html для атомарного обновления. app.js и style.css хранят исходники соответствующих блоков. Публикация в Pages через main.

Проверки и тесты не запускались по просьбе владельца.

Каменные фрагменты вырезаются из фотографической облицовки с учетом маски стен и летят из-за границ кадра по индивидуальным траекториям: смещение, поворот, дуга, легкая тень и замедление к точке посадки. Они не обрезаются общей маской фасада во время полета. Lora SemiBold 600 для заголовка; нижняя группа поднята на 2% высоты экрана.

У летящих элементов добавлена экструзия: непрозрачные минеральные торцы с зерном, объемная контактная тень, сдержанный наклон, фаска и оседание перед монтажом. Фрагменты крупнее, вращение меньше, интервал посадки длиннее. Это объемная отрисовка на Canvas в фиксированном ракурсе. Размеры заголовка и нижнего текста увеличены.
